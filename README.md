# Elektron navbat Telegram bot

Bot ketma-ketligi:
1. ➕ Navbat puli berildi → sana → mashina → summa
2. 💰 Shoferdan olindi → sana → mashina → summa
3. 📊 Hisobot → jami va farq

## Muhim
- `BOT_TOKEN` ni GitHub'ga yozmang.
- Mashinalar ro'yxati `bot.py` dagi `cars()` funksiyasida.
- Hozircha ma'lumotlar SQLite bazasida saqlanadi.
- Keyingi bosqichda sizning Excel faylingizga eksport/backup qo'shish mumkin.
